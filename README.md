# GodotPartyDefault · 云间跃行

从正式大厅的「原版小游戏派对」启用本包，2–8 人同时挑战各自的 World 1-1 关卡。默认限时 180 秒，房主可设 30–600 秒。入口需要 PartyAPI，不支持独立 F6 开局。

A/D 或方向键移动，Space/W 跳跃，Shift/X 加速，S/下方向键进入第四根水管的地下金币房。每个动作使用主要按键和一个备用按键，可在设置中修改。保留成长、受伤、踩怪、甲壳、顶砖、金币、隐藏奖励、地下室、三条生命和旗杆结算。按原型得分降序排名，同分并列；通关奖励和剩余时间奖励计入得分。失去一条生命不会重置联机回合总时限。生命耗尽、通关或时限到达后锁定个人成绩。

各客户端本地模拟，房主汇总有限范围内的成绩。断线者标为 withdrawn 且不获派对积分。网络回合不允许单机暂停和重开。输入绑定是本地偏好，可在正式设置页调整；不会向网络传输物理键。画质由原版协议管理。

观战者看到关卡及实时分数榜，当前不转播参赛者的逐帧角色位置。只支持 standard 普通局，没有资源下注或道具效果。

保留的是 temp_game/Platformer 的默认 World 1-1 关卡，未搬入旧云上花园关卡。地图参考来源及 Kenney Platformer Kit 许可证见 ASSET_SOURCES.md 与 assets/kenney/platformer-kit/；字体许可证随 third_party/ 保留。配色适配支持主工程的压缩纹理导入。
